# FabSteel Structural Installer — راهنمای سریع

مسیر کار: **تکلا ۲۰۲۴ → فایل `.fabsteel` → برنامه ویندوز (تست) → همان فایل (کم‌حجم) → اپلیکیشن اندروید**

## ۱) افزونه‌ی تکلا ۲۰۲۴ (`tekla-plugin/`)
**نصب (یک‌بار):**
1. روی ویندوز که تکلا ۲۰۲۴ دارد، پوشه `tekla-plugin` را کپی کنید.
2. `build.bat` را اجرا کنید (نیاز: .NET SDK یا Visual Studio 2022؛ بار اول اینترنت برای NuGet). اگر تکلا جای دیگری نصب است: `build.bat "D:\...\Tekla Structures\2024.0\bin"`.
3. `install.bat` را اجرا کنید: `FabSteelExport.exe` در `C:\FabSteel\Export` و ماکرو در پوشه ماکروهای تکلا قرار می‌گیرد.

**استفاده:**
1. تکلا را با مدل باز کنید → `Ctrl+F` → «FabSteel_Export» (بخش Macros) را اجرا کنید. (یا مستقیم `FabSteelExport.exe`.)
2. اول یک‌بار «تشخیص / تست اتصال به تکلا» را بزنید: تعداد قطعات و پیچ‌ها و نام خصوصیتی که **طول پیچ** را می‌دهد نشان داده می‌شود. همان نام را در کادر «خصوصیت طول پیچ» بنویسید.
3. «خروجی بگیر» → فایل `.fabsteel` فشرده ساخته می‌شود (برای بخشی از مدل: قطعات را انتخاب و «فقط قطعات انتخاب‌شده» را بزنید).
4. فایل را در نمایشگر ویندوز باز و تست کنید، بعد همان فایل را به موبایل بفرستید.

نکات دقت:
- طول پیچ فقط از خصوصیت گزارش تکلا خوانده می‌شود، هرگز حدس زده نمی‌شود؛ اگر پیدا نشود هشدار می‌دهد و پیچ فقط با قطر ثبت می‌شود.
- گرید و تراز: باید در مدل گرید X, Y, Z تعریف شده باشد. Z نباشد، تراز از ارتفاع تیر/ستون حدس زده می‌شود و در نمایشگر هشدار داده می‌شود.
- اگر `build.bat` خطا داد، متن خطا را برای Claude بفرستید تا همان لحظه اصلاح شود.

## ۲) برنامه ویندوز (`viewer/dist/FabSteelViewer.html` یا `electron/`)
- بدون نصب: فایل HTML را با Chrome/Edge باز کنید (آفلاین). یا `electron/` → `npm install` → `npm run dist` برای exe پرتابل.
- «باز کردن فایل» → `.fabsteel`. «نمونه آزمایشی» برای تست بدون تکلا.
- ۵ بخش: موقعیت قطعه · مشخصات درختی · گرید · تراز · پیچ و مهره. هر بخش دکمه PDF دارد (در Electron مستقیم ذخیره می‌شود؛ در مرورگر «Save as PDF»).
- **خروجی موبایل**: فایل `.fabsteel` فشرده (چند ده KB) یا HTML تک‌فایل که روی هر موبایل باز می‌شود.

## ۳) اندروید (`android/`)
1. Android Studio → Empty Views Activity، package: `ir.fabsteel.installer`.
2. `AndroidManifest.xml` و `MainActivity.kt` را جایگزین کنید، `assets/FabSteelViewer.html` را کپی کنید.
3. Build → APK. فایل `.fabsteel` را از تلگرام/واتساپ «Open with FabSteel» کنید یا داخل برنامه «باز کردن فایل».
- PDF: پنجره چاپ اندروید → Save as PDF.
- راه سریع بدون APK: فایل HTML تک‌فایل را مستقیم روی موبایل باز کنید.

## قواعد جستجو (قابل تنظیم با ⚙)
- قطعه «روی گرید»: ابتدا/انتهای محور قطعه حداکثر ۳۰۰ mm از خط گرید.
- قطعه «در تراز»: سطح بالا یا پایین قطعه حداکثر ۱۵۰ mm از تراز.
- قطعات متصل: از روی گروه‌های پیچ تکلا (قطعات هم‌مونتاژ جدا نشان داده می‌شوند).
- مدل سه‌بعدی: جعبه‌ی دور هر قطعه (برای حجم کم)؛ نه شکل دقیق برش‌ها و سوراخ‌ها.
